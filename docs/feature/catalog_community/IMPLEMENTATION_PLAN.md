# План реализации: Подключение глобальных книг к каталогу Community

**Документ:** Описание шагов для реализации UI подключения книг из глобальной библиотеки (`LibraryModule`) в репертуар сообщества (`RepertoireModule`) на стороне клиента.
**Основание:** ADR 0009 и ADR 0010.
**Доступ:** На данном этапе доступ к функционалу подключения/отключения книг разрешен **всем пользователям Community** (ролевая модель и проверка прав `REPERTOIRE_MANAGE` будут добавлены позже).

---

## 1. Концепция и цель

Вместо физического копирования песен, сообщество (Community) создает **привязку** (`BookAttachment`) к глобальным печатным изданиям. Песни из подключенных изданий появляются в основном каталоге сообщества в режиме "только для чтения" с автоматическим получением обновлений (исправлений опечаток и т.д.) от суперадмина.

## 2. Необходимые изменения (Что делаем)

### 2.1 API-слой (Ожидаемые контракты от бэкенда)

Фронтенду понадобятся следующие эндпоинты:

1. **Глобальная библиотека:** `GET /library/books` (уже существует, возвращает список всех доступных книг/серий).
2. **Привязки Community (требуется разработка на бэкенде):**
   - `GET /communities/:communityId/attachments` — список уже подключенных книг.
   - `POST /communities/:communityId/attachments` (body: `{ libraryBookId }`) — создать привязку.
   - `DELETE` или `POST /communities/:communityId/attachments/:attachmentId/archive` — архивировать (отключить) привязку.

### 2.2 UI-компоненты

1. **Страница "Настройки репертуара" (Repertoire Settings):**
   - Список уже подключенных книг.
   - Кнопка "Удалить/Отключить" для каждой привязки.
   - Кнопка "Добавить книгу из библиотеки", открывающая модальное окно.
2. **Модальное окно "Браузер библиотеки" (Library Browser):**
   - Список всех глобальных книг (запрос к `GET /library/books`).
   - Визуальное отличие (например, disabled состояние или галочка) для книг, которые уже подключены.
   - Кнопка "Подключить" для неподключенных книг.
3. **Обновление основного каталога (Song List):**
   - Выпадающий список фильтрации "Sammlung" (Книга) должен пополняться списком подключенных книг.

---

## 3. Последовательность реализации (Как делаем)

### Шаг 1. Согласование API и обновление типов

1. Утвердить с бэкенд-командой контракты эндпоинтов для управления `BookAttachment`.
2. Добавить TypeScript-интерфейсы в клиентское приложение (например, `BookAttachmentView`, `CreateAttachmentDto`).
3. Реализовать API-клиенты (fetch-функции) в слое сервисов `src/features/catalog/api/` (или `src/features/repertoire/api/`, если фича будет выделена в отдельную директорию).

### Шаг 2. Настройка React Query (State Management)

1. Создать хуки `useLibraryBooks()` для загрузки глобального списка книг.
2. Создать хуки `useCommunityAttachments(communityId)` для загрузки подключенных книг.
3. Создать мутации `useAttachBook()` и `useDetachBook()` с оптимистичным обновлением (optimistic updates) или инвалидацией кэша `communityAttachments`.

### Шаг 3. Верстка страницы "Настройки репертуара"

1. Создать новый роут, например `/communities/:communityId/repertoire`.
2. _Примечание: на данный момент доступ на страницу открыт для всех._
3. Сверстать список подключенных книг. Каждая карточка/строка должна показывать название книги и кнопку "Отключить".
4. Интегрировать хуки `useCommunityAttachments` и `useDetachBook`.

### Шаг 4. Верстка "Браузера библиотеки"

1. Создать компонент `LibraryBrowserModal`.
2. Вывести список `useLibraryBooks()`.
3. Написать логику вычисления статуса: пересечь `libraryBooks` с `communityAttachments`, чтобы определить, какие книги уже добавлены.
4. Добавить кнопку "Подключить" и привязать её к мутации `useAttachBook`.
5. Повесить открытие модального окна на кнопку "Добавить книгу" на странице репертуара.

### Шаг 5. Интеграция с основным браузером песен (Song Browser)

1. На странице просмотра песен Community (где будет список всех песен), добавить запрос `useCommunityAttachments()`.
2. Динамически сформировать опции для фильтра "Книга", используя полученные данные о привязках.
3. Убедиться, что для песен, источник которых — глобальная библиотека (`source: 'LIBRARY'`), скрыты кнопки редактирования (Read-only режим).
