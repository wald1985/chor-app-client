# Клиентская часть репертуара: план и статус

**Основание:** ADR 0009 (репертуар Community), ADR 0010 (библиотека), ADR 0007 (права).
**Серверная часть:** `chor-app-server/src/repertoire/` — готова (фазы C1–C6).
**Предшествующий документ:** `../catalog_community/IMPLEMENTATION_PLAN.md` (подключение книг).

## 1. Как это работает

Репертуар хора (`Community`) = **подключённые книги** библиотеки (`BookAttachment`, только чтение, живая ссылка) + **собственные папки** (`Folder`, «Mappe») с песнями `FolderSong`, плюс **собственные темы** (`Theme`), которые можно назначить любой видимой песне.

- Просмотр доступен любому члену хора.
- Запись (книги, папки, песни папок, темы) требует права `REPERTOIRE_MANAGE`. Сервер проверяет его всегда; клиент лишь скрывает недоступные действия.
- Ничего не удаляется, везде архивация (`archivedAt`).
- **Активный хор** — первое членство из `memberships` (переключателя пока нет).

## 3. Что реализовано (этапы 0–1)

Код: `src/features/repertoire/`.

| Файл                              | Назначение                                                                               |
| --------------------------------- | ---------------------------------------------------------------------------------------- |
| `types/repertoire.types.ts`       | `CommunitySongView` и связанные типы (повторяют ответ сервера)                           |
| `api/communitySongsApi.ts`        | `GET /communities/:id/songs` (параметры `search`, `themeIds`, `containerId` опциональны) |
| `hooks/useCommunitySongs.ts`      | Запрос TanStack Query, ключ `["repertoire", communityId, "songs", params]`               |
| `hooks/useActiveCommunity.ts`     | Активный хор = первое членство                                                           |
| `hooks/useCommunityPermission.ts` | Есть ли у пользователя право в хоре                                                      |
| `utils/songFilters.ts`            | Сортировка, список тем, фильтрация                                                       |
| `pages/RepertoireSongsPage.tsx`   | Страница для вкладок `lieder` (`mode="songs"`) и `themensuche` (`mode="themes"`)         |

Также `CommunityMembership` в `features/auth/types.ts` получил поле `permissions` (сервер отдаёт действующие права в `login` и `me`; у администратора — все).

### Поведение страницы

- Все песни хора загружаются **один раз**, фильтры работают на клиенте (около 2000 песен, мгновенная реакция, список тем строится из реальных данных).
- Сортировка: название сборника, затем номер с натуральным порядком («2» < «10», «22» < «22a»).
- Фильтры: поиск (название, номер, автор, аранжировщик, без учёта регистра), «Sammlung», «Thema».
- **Темы:** библиотечная и собственная тема с одинаковым названием (нормализация: trim и нижний регистр) показываются одним пунктом и находят песни обоих видов (ADR 0009).
- Таблица: номер, название с бейджем «Neu» (только песни папок), автор/аранжировщик, сборник, темы.
- Состояния: загрузка, ошибка, «Noch keine Lieder im Repertoire», «Keine Lieder gefunden», пользователь без хора.
- Ссылка «Repertoire-Einstellungen» видна только при `REPERTOIRE_MANAGE`.

### Решения

- Библиотечный каталог остаётся доступен всем авторизованным: кнопка «Katalog» в шапке (модалка) и страница `CatalogBrowserPage` на маршруте `/katalog` (без пункта навигации).
- Порядок сборников и папок: по названию (вопрос Q4 ADR 0009 закрыт для MVP).
- Автосоздание первой папки «Mappe» (Q7) — отложено на следующую итерацию.

### Тесты

Vitest + RTL: `communitySongsApi.test.ts`, `songFilters.test.ts`, `useCommunityPermission.test.tsx`, `RepertoireSongsPage.test.tsx`. Проверки `type-check`, `lint`, `format:check`, `build` проходят.

## 4. План следующих этапов

**Этап 2 — Mappen.** Блок «Mappen» в настройках: список, создание, переименование, архивация (409 при дубле названия — показать у поля). Страница папки `/communities/:id/repertoire/folders/:folderId`: песни папки, добавление и правка (номер, название, автор, аранжировщик, `isNew`), архивация. Номер песни и папка после создания не меняются.

**Этап 3 — Themen.** Блок «Themen»: список и создание собственных тем. Диалог «Themen zuweisen» на песне (`PUT /songs/:songId/themes`), доступен и для песен книг.

**Этап 4 — Уборка.** Удалить `utils/communityRepertoireStorage.ts` и ветку копирования в `CatalogModal.tsx`; закрыть страницу настроек и действия с книгами правом `REPERTOIRE_MANAGE`; экран «Mitglieder» для администратора (`GET /members`, `PUT /members/:id/permissions`).

## 5. Открытые вопросы

- Автосоздание первой папки (Q7).
